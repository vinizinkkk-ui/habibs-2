# LULIB'S22

Site de paródia independente em HTML, CSS, JavaScript, Vite e Three.js.

## Como executar
1. Abra esta pasta no VS Code.
2. Abra o terminal.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço local indicado pelo Vite (normalmente http://localhost:5173).

O site precisa de internet para carregar as fotos de demonstração do Unsplash e a fonte do Google Fonts. O modelo 3D é construído em código Three.js e não depende de imagem externa. Não há backend nem pagamentos reais.

Os textos são paródias e as imagens são ilustrativas. Não existe vínculo com Habib's, PT ou PL.
